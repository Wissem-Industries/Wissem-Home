# Changelog

All notable changes to Wissem Home are documented in this file.

The project follows [Semantic Versioning](https://semver.org/).

## [0.1.4] - 2026-09-23

### Changed

- Reworked all French and English portfolio copy into a concise, impersonal style.
- Harmonized the wording of experience, education, project, profile, and contact content.

## [0.1.3] - 2026-09-23

### Fixed

- Preserved the WissemUI card border when hovering portfolio cards.
- Replaced the conflicting hover shadow with a subtle surface change and one-pixel lift.

## [0.1.2] - 2026-09-23

### Fixed

- Serialized tagged releases so installation, checks, image publishing, and Dokploy deployment run in the correct order.
- Restored reliable automatic production deployments from release tags.

## [0.1.1] - 2026-09-23

### Fixed

- Kept animated sections visible when switching between French and English.
- Stabilized translated list identities and registered dynamically rendered reveal elements.

## [0.1.0] - 2026-09-21

### Added

- Initial public release of the rebuilt portfolio using Nuxt, WissemUI, Bun, and Biome.
- French and English content, projects, contact form, SEO, responsive layouts, and light/dark themes.
- Container publishing and Dokploy production deployment workflow.
